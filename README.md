# VeriFaith 🛡️

**Verifiable Faithfulness Evaluation for RAG Systems**

VeriFaith is an automated evaluation pipeline and API for assessing the faithfulness (factuality) of answers generated by Retrieval-Augmented Generation (RAG) systems. It systematically detects hallucinations by decomposing generated answers into atomic claims and strictly verifying each claim against the provided source documents.

---

## 🌟 Key Features

*   **Atomic Claim Decomposition**: Uses LLMs (via Groq/LLaMA 3) to break down complex generated answers into simple, single-fact declarative statements.
*   **Dense Span Retrieval**: Automatically chunks source documents and uses semantic search (`SentenceTransformers` + `FAISS`) to locate the exact sentence that might support or contradict a claim.
*   **Cross-Encoder Entailment**: Employs an advanced Natural Language Inference (NLI) model (`DeBERTa-v3`) to actively classify the relationship between the claim and the source text as `ENTAILMENT`, `CONTRADICTION`, or `NEUTRAL`.
*   **Contradiction Prioritization**: Actively re-ranks retrieved spans to identify contradictions over weak neutral matches, ensuring hallucinations are aggressively caught.
*   **FastAPI Integration**: Provides a high-performance, easy-to-use REST API for seamless integration into existing MLOps or RAG pipelines.

---

## 🏗️ Architecture Pipeline

The VeriFaith codebase is cleanly separated into a modular, 4-step pipeline:

1.  **Claim Extractor** (`claim_extractor.py`)
    Prompts `llama-3.3-70b-versatile` (via Groq) to accurately separate the RAG output into an array of isolated factual claims without losing context.
2.  **Span Retriever** (`span_retriever.py`)
    Splits the original source documents into sentences. Embeds them using `all-MiniLM-L6-v2` and efficiently indexes them inside FAISS for rapid similarity retrieval. Retrieves the top-K most similar source sentences for every extracted claim.
3.  **Entailment Checker** (`entailment_checker.py`)
    Executes a Cross-Encoder (`cross-encoder/nli-deberta-v3-base`) on the (`Source Sentence`, `Claim`) pairs. It assigns an NLI score ensuring rigorous entailment checking.
4.  **Scorer** (`scorer.py`)
    Compiles the judgments into an aggregate report. Calculates the global **Faithfulness Score** (Supported Claims / Total Claims) and flags any unverified or contradicted statements.

## 🚀 Getting Started

### 1. Prerequisites

*   Python 3.9+
*   A [Groq API Key](https://console.groq.com/) for the claim extraction model.

### 2. Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/yourusername/verifaith.git
cd verifaith
pip install -r requirements.txt
```

*(Note: PyTorch will install automatically, but if you want GPU support, ensure you install the appropriate PyTorch version for your CUDA toolkit).*

### 3. Environment Variables

Create a `.env` file in the root directory and add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key_here
```

### 4. Running the API

VeriFaith runs as a FastAPI application. Start the server with `uvicorn`:

```bash
uvicorn verifaith.api:app --reload
```

The API will be available at `http://127.0.0.1:8000`.
You can access the interactive Swagger documentation at `http://127.0.0.1:8000/docs`.

## 🔌 API Reference

### Evaluate a RAG Response

**Endpoint:** `POST /evaluate` (or default evaluation endpoint deployed in your API)

**Request Body:**

```json
{
  "answer": "The Eiffel Tower was built in 1889 and stands 330 metres tall.",
  "source_docs": [
    "The Eiffel Tower is a wrought-iron lattice tower on the Champ de Mars in Paris, France.",
    "Constructed from 1887 to 1889 as the centerpiece of the 1889 World's Fair.",
    "It is 330 metres tall, about the same height as an 81-storey building."
  ],
  "include_full_report": true
}
```

**Response Overview:**

Returns a rich JSON object outlining:
*   `faithfulness_score`: A percentage (0.0 to 1.0) of supported claims.
*   `total_claims`, `supported`, `unverified`, `contradicted`: Hard counts of the NLI metrics.
*   `claim_breakdown`: If requested, detailed NLI outputs mapping every claim to its exact source sentence and confidence score.
